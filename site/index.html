Un visor VNC libre, hecho para trabajar con UltraVNC

Lucarna te deja ver y controlar otro equipo desde macOS, Windows o Linux, y mover archivos con el protocolo de transferencia de UltraVNC. Gratis y de código abierto.

Qué es VNC, en una frase

VNC permite ver la pantalla de otro equipo y manejarlo con tu teclado y tu ratón, a través de la red.

  1. Saludo. Cliente y servidor acuerdan la versión del protocolo.
  2. Acceso. El servidor pide una contraseña, o usuario y contraseña de Windows en UltraVNC.
  3. Pantalla. El cliente pregunta qué cambió y el servidor manda solo las zonas que cambiaron, comprimidas.
  4. Entrada. Cada tecla, movimiento o clic viaja al servidor como un mensaje pequeño.

Lo que hace hoy

Un visor ligero, con pocas dependencias, que se siente como una aplicación nativa.

Pantalla fluida

Codificaciones Tight (con JPEG para enlaces lentos), ZRLE, Zlib, Hextile, CopyRect y Raw. El cursor local se pinta sin retraso.

Pensado para UltraVNC

Inicio de sesión MS-Logon II y III con usuario y contraseña de Windows, repetidor (host:puerto o ID:1234) y chat de texto.

Transferencia de archivos en pruebas

Navegador de dos paneles, local y remoto, con descargas, subidas por arrastrar y soltar, carpetas, renombrar y borrar.

Libreta de direcciones

Conexiones guardadas con miniatura de la pantalla, etiquetas, favoritos y vista en cuadrícula o lista.

Contraseñas a salvo

Se guardan en el llavero de tu sistema operativo. Nunca se escriben en un archivo.

Barra de sesión

Solo ver, ajustar a la ventana o 1:1, pantalla completa, menú de teclas especiales y Ctrl+Alt+Supr.

En desarrollo: túnel SSH integrado y archivos por SFTP, para cifrar la conexión sin instalar nada en el servidor. Mira la hoja de ruta.

Instalar

Descarga el instalador de tu sistema desde la última versión.

macOS

Como Lucarna aún no tiene firma de Apple, lo más simple es compilarla con Rust:

git clone https://github.com/BuilderJoy/lucarna.git
cd lucarna
./packaging/macos/install-local.sh

También hay un .dmg universal; macOS lo bloqueará hasta que lo permitas en Ajustes del Sistema → Privacidad y seguridad.

Windows

Descarga el instalador …-windows-x64-setup.exe y ábrelo. Se instala para tu usuario, en español o inglés.

Linux

En Debian o Ubuntu usa el paquete .deb:

sudo apt install ./lucarna_*_amd64.deb

También hay un .tar.gz para otras distribuciones.

Cómo funciona por dentro

Cuatro piezas, y una regla de seguridad que las atraviesa.

La ventana

Muestra la libreta de direcciones y la pantalla remota, y captura tu teclado y tu ratón.

La sesión

Cada conexión corre en su propio hilo, así la ventana nunca se congela esperando datos.

El lector

Es el único que lee del servidor: identifica cada mensaje y lo entrega a pantalla, portapapeles, chat o archivos.

La pantalla en memoria

Guarda la última imagen y solo redibuja la zona que cambió.

Regla de seguridad: el servidor se trata como no confiable. Cada tamaño y cada rectángulo que llega se valida antes de usarse.

Estado del proyecto

Lucarna está en la versión 0.x y todavía le faltan pruebas. Preferimos decirlo claro.

  • Funciona: pantalla, teclado, ratón, libreta de direcciones, contraseñas en el llavero, MS-Logon, chat y repetidor.
  • En pruebas: la transferencia de archivos y el portapapeles, que todavía se están probando con distintos servidores.
  • Sin confirmar: ninguna función se ha validado aún contra un UltraVNC Server real. Se seguirá en 0.x hasta hacerlo.
